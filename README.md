# Tang Nano 20K - Donkey Kong Jr
![Model](TN20K-DonkeyKongJR.jpg)

Donkey Kong Jr Arcade verilog code ported to a Tang Nano 20K FPGA Board by pinballwiz.org 2025.  
Works with VGA Monitor. Original code by Katsumi Degawa.

## Basys 3 port

Digilent Basys 3 version, tested on hardware: see
[TN20K-DonkeyKongJR/basys3/README.md](TN20K-DonkeyKongJR/basys3/README.md).

The port changes four core files shared with the Tang Nano 20K project. The Tang Nano 20K
project still builds without errors, but has not been tested on Tang Nano 20K hardware.
